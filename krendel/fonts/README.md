# The code's fonts

Krendel's settings offer these fonts for the code. `web/fonts.css` gives each its family, and a browser loads one only when the code takes it. Each folder has the font's license.

| `8bit` | ZX Spectrum, with its bold and italic, ZX Spectrum 6x8, Amstrad CPC, MSX, SAM Coupé, Sinclair QL, Cambridge Z88 | Drawn by `web/make-fonts.py` from the bitmaps in [ZEsarUX](https://github.com/chernandezba/zesarux)'s `src/charset.c` at `e6b7e0c`, Copyright (C) 2013 Cesar Hernandez Bano. The bold is each row widened by a pixel, the italic the top four rows a pixel right of the bottom four, and the 6x8 drawn by hand from the ROM's glyphs in `zx-spectrum-6x8.png`, a pixel for each of the font's. The typefaces are the machines' own | GPL-3.0-or-later, `COPYING.txt` |
